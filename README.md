# Кикер-прогнозы MVP

MVP фановой игры по турниру по кикеру: участники делают прогнозы на победителей конкретных матчей, админ вручную закрывает прогнозы и выбирает победителей, лидерборд считает баллы.

## Стек

- Next.js App Router
- TypeScript
- Tailwind
- Supabase
- Простая админ-защита через пароль из `.env`
- Без платежей и реальных денежных ставок

## Структура базы данных

- `teams`: команды и два игрока.
- `matches`: раунд, две команды, дедлайн, статус, победитель.
- `participants`: уникальные имена участников.
- `bets`: один прогноз участника на один матч.
- `scores`: очки и количество угаданных исходов.
- `leaderboard`: view для рейтинга.
- `bets_with_details`: view для админского списка ставок.

## Быстрый запуск

1. Создайте проект в Supabase.
2. Откройте SQL Editor и выполните `supabase/schema.sql`.
   Этот файл создает таблицы, ограничения, RLS-политики, view для лидерборда и функцию пересчета очков.
3. Скопируйте переменные окружения:

```bash
cp .env.example .env.local
```

4. Заполните `.env.local`:

```bash
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-publishable-key
SUPABASE_SECRET_KEY=your-secret-key
ADMIN_PASSWORD=your-admin-password
```

`SUPABASE_SECRET_KEY` нужен только серверной админке. Не публикуйте его в браузере и не добавляйте в `NEXT_PUBLIC_*`.

5. Установите зависимости и запустите приложение:

```bash
npm install
npm run dev
```

6. Откройте:

- Главная: `http://localhost:3000`
- Лидерборд: `http://localhost:3000/leaderboard`
- Админка: `http://localhost:3000/admin`

## Правила MVP

- Участник один раз вводит ник, ник сохраняется в `localStorage` на устройстве.
- При следующих визитах сайт показывает сохраненный ник и дает продолжить или сменить его.
- Участник выбирает команду большими кнопками в открытом матче.
- Ник уникален без учета регистра и пробелов по краям.
- Один ник может сделать только один прогноз на матч.
- Прогноз нельзя менять после сохранения.
- После дедлайна или закрытия матча прогноз не принимается.
- Когда админ выбирает победителя, Supabase пересчитывает очки.
- Баллы зависят от раунда: `1/8 финала` = 1, `1/4 финала` = 2, `1/2 финала` = 3, `финал` = 5.

## Админка

Админ может:

- создавать и редактировать команды;
- создать 16 стран ЧМ-2026 с игроками `TBD`;
- создавать матчи;
- сгенерировать 1/8 финала из ровно 16 команд случайной жеребьевкой;
- сгенерировать 1/4, 1/2 и финал после полного выбора победителей предыдущего раунда;
- закрывать прием ставок;
- выбирать победителя;
- менять дедлайн матча;
- фильтровать матчи и прогнозы;
- удалять команды;
- очищать тестовые данные;
- запускать пересчет баллов;
- смотреть все прогнозы.

Пароль хранится только в `.env.local` как `ADMIN_PASSWORD`.
